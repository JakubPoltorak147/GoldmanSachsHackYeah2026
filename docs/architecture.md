# Architecture

## Current status

No application components have been implemented.

There is no implemented interaction model, control or policy engine, request flow,
persistence, external integration, runtime, deployment, observability, or trust-boundary
architecture to document yet.

The repository currently contains documentation and OpenSpec workflow configuration.
Product goals and conceptual architectural direction live in
[project context](project-context.md); they are not implemented architecture.

## Keeping this document current

Design decisions belong first in the reviewed and approved OpenSpec change that
introduces them. Update this document after implementation and verification to
reflect components and behavior that actually exist.
